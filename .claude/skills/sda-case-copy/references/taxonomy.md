# Fixed tags for site filters

The site will filter cases by industry and by service, so the Overview tags use fixed names. Spell them exactly as below. Add a new value only when nothing fits, and add it here in the same session.

## Industry (first tag of the Industry row = the filter value)

The first Industry tag is always one of these. The breadcrumb uses the same name: `Case Studies > <Industry>`, and the URL its slug: `/cases/<slug>/<keyword-slug>/`.

The second (and third) Industry tag is a free niche word that helps SEO, ≤ 22 chars: «Mental Health», «Music & Nightlife», «Senior Care», «Crypto».

## Product (2–3 tags from this list)

Web Platform · Mobile App · Marketplace · SaaS Platform · Dashboard · Admin Panel · Website · AI Assistant · ERP System · CRM System · Browser Extension · API & Integrations

## Services (2–3 tags from this list)

Discovery · MVP Development · Web Development · Mobile App Development · UI/UX Design · AI Development · Data & BI Dashboards · Legacy Modernization · Product Rescue · Support & Maintenance · QA & Testing · DevOps & Cloud · Tech Audit · Team Extension

**AI:** if SDA built or worked on any AI feature of the product (ML, LLM, AI assistant, speech AI, AI matching, AI insights), the Services row must include `AI Development`; an audit-only or design-only project mentions the product's AI in text but gets no tag, and the What we delivered paragraph names the AI feature in plain words. If there is no AI, never add it.

## Team & Timeline

`<N> specialists · <duration>`. Notion start/end dates usually include long support, so they are not the development time. Estimate the development phase from the scope (an MVP is usually 3–6 months, a redesign 1–3 months, a rescue phase 2–4 months) and, when the client stayed for support, add it: `4 months + support`. A figure on the current site or in the presentation wins over the estimate.

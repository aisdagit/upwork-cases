# Правила для профілів

## Формула профілю 2026 (з аудиту MARS, 6.08.2026)

Профіль продає швидке рішення конкретної бізнес-проблеми, а не «фрилансера». Алгоритм показує найрелевантніший досвід; після скасування Specialized Profiles є один основний профіль.

Перевіряти кожен профіль за цими пунктами:
1. Позиціонування зрозуміле за 5 секунд: що робить, для кого, який результат.
2. Текст про проблему й результат клієнта, а не «I have / I know».
3. Перші 250 символів опису: проблема → рішення → результат → доказ (цифра).
4. Один головний меседж; одна спеціалізація, а не «роблю все».
5. Без «води» (passionate, hardworking), лише конкретика і цифри.
6. Портфоліо: було → що зробили → результат → цифри → технології; результат видно вже в назві проєкту.
7. Ключові слова природно в Title / Overview / Skills / Portfolio / Employment, без напихання.
8. Соціальний доказ: Top Rated, JSS, earnings, відгуки, сертифікати.
9. Немає суперечностей між Title, Overview, Skills, Portfolio, Employment History.
10. Спокійний CTA; профіль заповнений на 100% (доступність, верифікація, каталог).

## Цифри і кейси

- Цифри в текстах — лише з бази SDA: таблиця проєктів у Notion (`Контекст SDA/База знань про компанію/Projects SDA …csv`), поточне портфоліо на Upwork, сторінки кейсів на sda.company, або від команди. Не вигадувати й не округлювати вгору.
- Кейси з позначкою **Fake** у колонці Real/Fake (`Кейси — сайт, Notion, Figma.csv`) не використовувати в профілях — це не реальні проєкти.
- Проєкти під NDA — без назви клієнта і логотипа, лише галузь і тип продукту.
- Перевірені цифри (на 11.11.2026): 150+ проєктів, 20+ країн, з 2019, AWS Select Tier Services Partner; FCT — продажі ×10; Five — запуск за 5 міс., економія $200K+, залучено $5M; Samata — відповідь з 10–15 с до 1 с; Kyle — продуктивність ×3, крешів −50%, DAU +18%; HeyBodhi — пілот на 350 освітян; Agroplace — 20+ джерел даних, бюджет у 10 разів менший; MeatMap — MVP за 3 міс.; Rewarded — утримання +30%.

## Ціни послуг SDA (для каталогу)

Code аудит $500, QA аудит $500, Design аудит $500; Product Definition Sprint $900; Product Readiness Sprint від $2,500; Enterprise Product Architecture від $6,000; консультація CEO 30 хв $100 / 60 хв $200. SaaS MVP у каталозі агенції — $5k / $10k / $15k (ринкові ціни, рішення від 11.11.2026).

## Технічні обмеження полів
- Title особистого профілю — до 70 символів; Overview — до 5000; скілів — до 20 (агенція — 15).
- Роль у Employment History — до 50 символів.
- Скіли — лише точні назви з каталогу Upwork.

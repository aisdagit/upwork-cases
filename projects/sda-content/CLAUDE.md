# SDA LinkedIn content — робоча папка

Тут готуються пости LinkedIn для трьох каналів SDA: **CEO** (Oleksandr Shubin), **SDA** (сторінка компанії), **Kateryna** (Kateryna Shubina, COO).

Порядок роботи — 4 скіли по черзі:
1. `sda-content-plan` — вибір кампанії, картка кампанії, контент-план від цілі (людина апрувить картку і план); результат — Excel кампанії (`tools/campaign_xlsx.py`).
2. `sda-content-angle` — кут і бриф для кожного поста.
3. `sda-content-writer` — текст англійською + опис візуалу.
4. `sda-content-critic` — перевірка, фінальний текст, CSV для Google-таблиці.

Папки:
- `kb/` — правила, профілі персон, банк позицій CEO, еталони `gold_examples.md`;
- `data/` — експорти таблиць і архів Telegram CEO;
- `tools/` — скрипти;
- `output/` — результати по періодах;
- `feedback/` — оцінки маркетологині.

Головні правила (детально — `kb/00_rules.md`): аудиторія — потенційні клієнти; жодних внутрішніх цифр продажів, цін, проблем з клієнтами, конкурентів поіменно; нічого не вигадувати; історія з власним елементом, а не загальні поради. Брифи — українською, пости — англійською.
